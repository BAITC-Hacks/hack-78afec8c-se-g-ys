# hack-78afec8c-se-g-ys
Hackathon team repository for SE G_YS

## Локальный запуск

Первый пользовательский путь issue #2 показывает исходные данные пяти районов и каталог 14 мероприятий на русском языке.

```bash
npm start
```

Откройте `http://localhost:3000`. Проверка:

```bash
npm test
```

Тесты карты открывают локальную страницу в headless Google Chrome. Для них нужен
установленный `google-chrome`; альтернативный путь можно задать через `CHROME_BIN`.
Приложение и остальные тесты используют Node.js 22+ без установки npm-зависимостей.

Карта показывает пять условно расположенных районов модели. Выберите район
мышью, Enter или пробелом; кнопка «Весь город» сбрасывает выбор. Рядом с SVG
есть текстовые кнопки районов, показатели и словесные статусы. Переключатель
«Русский / Қазақша» переводит карту и её описание, сохраняя выбранный район,
черновик и расчёт. До принятия карта показывает исходные показатели, решения,
стоимость и готовность черновика. После принятия она берёт показатели Q8 и Score
из того же серверного результата, что и основная панель. Цвет отражает статус
самого низкого показателя района; схема не изображает реальные границы.

Каталог также доступен через `GET /api/catalog`.

Принятие сценария выполняется через `POST /api/scenarios/accept` с JSON-полем `decisions` из пяти решений. Сервер возвращает причины отказа без результата для невалидного набора и детерминированный результат Q8 для принятого сценария.
